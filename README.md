# ☁️ La Nube — Knowledge Assistant

**Document classification, semantic search, recommendations, a chatbot and a knowledge graph for a neighbourhood supermarket with a butcher counter.**

*Felix Yael · Universidad Tecmilenio · Knowledge Management project, Phase 3 (final prototype)*

**Live app:** _pending deployment on Streamlit Community Cloud_

---

## The organisation

**La Nube** is a fictional mini-supermarket in Mexico: 2 registers, 1 butcher counter with a label scale and a local server that keeps selling when the internet goes down. Its knowledge lives in 102 documents: manuals, reports, sales documents, inventory records and policies. The procedures (register keys, cash cut, credit, card terminal, backups, PIN security) follow the store's real point-of-sale manuals; sales figures are illustrative, and names, network details, costs and suppliers are left out. New cashiers ask the same questions every week and the owner spends time looking for reports.

## What the system does

| Tab | Function | How |
|---|---|---|
| 🔎 Search | Find documents by meaning, not only exact words | Hybrid score: TF-IDF + WordLlama embeddings (cosine) |
| ⭐ Recommendations | "Related documents" for each doc + "Recommended for you" in the sidebar | Cosine similarity between embeddings; session profile = recency-weighted mean of recent queries and opened docs |
| 💬 Ask the assistant | Answers questions from the documents, with citations like `[D04]` | Retrieval (top-3) + extractive answer; LLM-generated answer if a `DEEPSEEK_API_KEY` secret is set, falling back to extractive on any error; refuses off-topic questions |
| 🏷️ Classify | Predicts the category of a new document | WordLlama embeddings + logistic regression (best of 4 models) |
| 🕸️ Knowledge graph | Explore documents ↔ categories ↔ topics ↔ ontology classes | Phase I OWL ontology expanded to 558 triples (rdflib) → NetworkX → PyVis, with filters, focus mode and similarity edges |
| 📊 Evaluation | All metrics below, live | `outputs/metrics.json` generated by `evaluate.py` |

```mermaid
flowchart LR
    CSV[(102 documents<br/>+ topics)] --> TF[TF-IDF]
    CSV --> EMB[WordLlama embeddings]
    TTL[Phase I ontology<br/>phase1.ttl] --> ONT[Expanded ontology<br/>558 triples]
    CSV --> ONT
    TF --> CLF[Classifier]
    TF & EMB --> SRCH[Hybrid search]

    SRCH --> BOT[Chatbot<br/>extractive / LLM]

    EMB --> G
    CLF & SRCH & REC & BOT & G --> APP[Streamlit app]
    J[(judgments.json<br/>hand-labelled)] --> EV[evaluate.py] --> M[(metrics.json)] --> APP
```

## Results

All figures come from `python evaluate.py` and hand-labelled ground truth in `data/judgments.json`.

**Classification** (stratified 5-fold CV, 102 docs, 5 classes)

| Model | Accuracy | Macro precision | Macro recall | Macro F1 |
|---|:-:|:-:|:-:|:-:|
| Naive Bayes (TF-IDF) | 0.74 | 0.75 | 0.74 | 0.72 |
| LogReg (TF-IDF) | 0.78 | 0.79 | 0.79 | 0.78 |
| **LogReg (embeddings) — in app** | **0.85** | **0.86** | **0.85** | **0.85** |
| LogReg (TF-IDF + embeddings) | 0.83 | 0.84 | 0.84 | 0.83 |

**Retrieval** (26 judged queries: 13 keyword, 13 everyday paraphrase)

| Engine | Keyword P@3 / R@5 / MRR | Paraphrase P@3 / R@5 / MRR |
|---|:-:|:-:|
| TF-IDF (Phase I) | 0.82 / 0.82 / 1.00 | 0.23 / 0.31 / 0.52 |
| Embeddings | 0.92 / 0.84 / 0.92 | 0.51 / 0.55 / 0.76 |
| **Hybrid — in app** | **0.92 / 0.84 / 1.00** | **0.49 / 0.53 / 0.76** |
| MiniLM-L6 (offline comparison) | 0.92 / 0.84 / 0.96 | 0.51 / 0.64 / 0.86 |

**Recommendations** (16 seed docs with hand-labelled related sets): embeddings P@5 0.50, nDCG@5 0.67, against 0.06 for random documents of the same category. Query history raises P@5 on ambiguous follow-up queries from 0.40 to 0.51.

**Chatbot** (18 questions with known answers): the right source is in the top 3 for 18/18; the answer contains the expected fact in 17/18; 3/3 off-topic questions are refused.

**Usability:** SUS + 3 tasks with real users — see `usability/`. Results appear in the app when collected.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
python evaluate.py            # regenerate outputs/metrics.json (add --minilm for the offline comparison)
python knowledge.py           # self-check
```

Optional LLM answers: create `.streamlit/secrets.toml` with `DEEPSEEK_API_KEY = "..."` (git-ignored), or set it in Streamlit Cloud → App settings → Secrets.

## Structure
